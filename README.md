# BookAnnotationBrowserExtension
## Downloading Annotate
Unfortunately, Annotate is not available on the Chrome extension store, so to download it, you'll have to download this repository as a folder before heading over to chrome://extensions, enabling developer mode, and loading the aforementioned folder as an unpacked extension. 

I am looking into submitting it for review on the Chrome Web Extension store, so I will continue to update this with the status. 

This isn't the most reliable with PDFs, so I'm looking to work on that.
